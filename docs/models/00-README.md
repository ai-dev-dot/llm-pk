# 模型特有问题档案

记录每个参与 PK 的模型在接入、测试中发现的**特有问题**（症状 / 复现 / 根因 / 社区证据 / 规避方案），以及本项目最终采用的配置与理由。

## 用途

1. **开局配置决策** —— 新局前查档案，避开已知坑（如 GLM 思考过度、某端点流式不稳）；
2. **公众号文章素材** —— PK 结果文章里描述「参与模型的问题」时直接引用；
3. **新模型接入参考** —— 接入新模型时按本目录模板建档，复用已验证的规避手段。

## 规则

- 每个模型（或同家族）一个文件：`docs/models/<模型名>.md`；
- **在 `config.json` 的 `models.<name>` 加 profile 时，同步新建/更新对应档案文件**（两者一一对应）；
- 发现新问题、新证据（含社区 issue 链接、实测数据）随时补充，注明日期；
- 配置与直觉冲突时以**实测**为准，档案要写清「为什么这样配」；
- 社区证据优先引官方渠道：智谱文档 `docs.bigmodel.cn`、官方 GitHub `zai-org`/`THUDM`、相关项目 issue。

## 统一模板字段

```markdown
# <模型名> 特有问题档案
## 基本信息       模型名/厂商/协议/anthropic|openai/端点
## 配置档案       本项目 config.json 推荐 profile(thinking 透传/max_tokens/超时)+ 为什么
## 已知问题       每条:症状 → 复现 → 根因 → 证据(社区链接) → 本项目应对
## 实测数据       耗时/思考长度/token/成本 观测(注明对局与配置)
## 结论与建议     接入结论、继续观察项
```
